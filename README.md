# BrightestNeonLauncher-CDN

Репозиторий для хранения манифестов игр, метаданных и ссылок на скачивание.
Используется лаунчером для получения актуальной информации об играх и DLC.

## Структура

```
games/
  semitone-resonance/
    manifest.json       ← Метаданные игры (версия, DLC, ссылки)
    icon.png            ← Иконка для sidebar лаунчера (128x128)
    logo.png            ← Логотип игры
    background.jpg      ← Фоновое изображение для лаунчера
launcher/
  latest.json           ← Информация о последней версии лаунчера
```

## Как это работает

1. Лаунчер при запуске запрашивает `manifest.json` каждой игры из CDN
2. Получает актуальную версию, ссылки на скачивание DLC, новости
3. DLC скачиваются напрямую из GitHub Releases соответствующего репозитория игры
4. Обновления самого лаунчера — через GitHub Releases репозитория лаунчера

## Добавление новой игры

1. Создать папку в `games/` с id игры
2. Добавить `manifest.json` с метаданными
3. Добавить иконку, логотип и фон
4. В лаунчере в `games.json` добавить `cdn_manifest_url`
